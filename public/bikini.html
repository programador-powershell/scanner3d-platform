BIKINI · backend experimental

Blender 5.3 não oficial, em pacote Windows x64. Ferramentas de Geometry Nodes e materiais para trabalhar em cópias dos assets. Não é um serviço de reconstrução por IA.

Fidelidade da personagem: não validada por esta integração.

O probe mede exportação e reimportação de um objeto técnico. Descobrir um nó não prova seu solver. Nenhum desses resultados aprova um personagem, rig, tecido ou build da Unreal.

Instalação e último probe

Consultando o controlador…

Esta página apenas lê os registros. Não inicia Blender, GPU, download ou cobrança.


Configurar na máquina Windows executora
$env:BIKINI_PATH = 'D:\Tools\BIKINI\blender.exe'
$env:BIKINI_ALLOW_UNOFFICIAL = '1'
npm run bikini:check
npm run bikini:probe
npm run start:bikini
Mantenha o pacote completo. A revisão e o hash do executável estão em config/bikini.lock.json. O comando npm start continua usando Blender normal, salvo seleção explícita via BLENDER_BACKEND=bikini.


Assar uma camada de Geometry Nodes
npm run bikini:bake -- "D:\Alice\estudo.blend" "COL_Ornamentos" "D:\Alice\candidatos\ornamentos-001"
Exige uma collection existente de malhas estáticas. Produz GLB, FBX, BLEND e relatório em pasta nova. Recusa rig, pesos, shape keys e cloth: essa operação não pode destruir o skinning para aparentar sucesso. Materiais procedurais exigem bake próprio.
