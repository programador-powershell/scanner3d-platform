# Diagnóstico das sombras da renda

A ficha 1 permanece sem alterações. Os recortes ampliados da mesma foto comparam o limiar anterior e três interpretações de contraste local. Nenhuma dessas máscaras foi aprovada para substituir a renda: as regiões grandes continuam confundindo fios, vazados e sombras. A correção seguinte deve reconstruir a trama e o volume das dobras, com nova comparação das quatro vistas. Este diagnóstico não gerou nem publicou um modelo.
