# Reforços abaulados: tiras atravessando o tecido

O ensaio v067 aumentou o volume frontal dos reforços e transferiu suas costuras e laços. As quatro vistas reais mostram as tiras de suspensão desaparecendo no meio dos reforços: seu trajeto anterior atravessou o tecido mais abaulado. O resultado foi rejeitado e não substituiu a fundação publicada. A correção seguinte ajusta as superfícies reais das tiras e seus suportes, mantendo os encontros no cinto e nos fechos.
