# Alice Coelho inteira — checkpoint v1048

GLB e FBX inteiros com vestido, reimportados em sessões independentes e verificados visualmente. Relógio/laço traseiros integrados; o pacote preserva o personagem completo. Baixe os binários na [release verificada](https://github.com/programador-powershell/project-alice-game/releases/tag/coelho-whole-clock-uv4k-wip-v1048). Caminhos completos no disco F, tamanhos e hashes estão no manifesto. Blender de autoria integral v1041 permanece separado na raiz compartilhada.

Este é um checkpoint estático intermediário. Não possui rig/animações; identidade comum, altura anatômica 168 cm, camadas inferiores, cabelo individual, tecido, física, expressões e gameplay continuam em produção. A revisão visual do checkpoint não constitui aprovação de fidelidade final. Nenhum crédito adicional do Tripo foi utilizado.

O usuário autorizou continuar sem Vercel. Esta entrega publica o checkpoint diretamente no GitHub; não alega deploy ou atualização do site. O estudo local de encaixe do esqueleto comum permanece separado e não está incluído nos modelos desta release.
